# TCGA-GBM-RNAseq-Differential-Expression-Analysis-using-Python

## Objective

Identify differentially expressed genes between glioblastoma
tumor samples and normal brain tissue using publicly available
TCGA data.

## Dataset

TCGA-GBM RNA-seq STAR-count data obtained from the
GDC portal.

## Methods

- Python
- pandas
- NumPy
- PyDESeq2
- matplotlib
- Gene Ontology enrichment
- GSEA

## Workflow

Raw counts
→ QC
→ filtering
→ normalization
→ PCA
→ differential expression
→ pathway analysis
